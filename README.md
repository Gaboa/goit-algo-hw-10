# Завдання 1. Видача решти

Якщо взяти що `A` — сума, а `K` — кількість номіналів

Жадібний алгоритм проходить номінали один раз, тому працює за `O(K)` часу
Динамічне програмування обчислює оптимум для кожної суми від `1` до `A`, перевіряючи номінали: його часова складність — `O(A · K)`

На заданому наборі номіналів при використанні жадібного і динамічного алгоритма я отримував однаковий розподіл по монетах

При цьому динамічний алгоритм працює довше для великих сум, так як для кожного варіанта суми меншої за задану ми підраховуємо оптимальну комбінацію монет

Висновок - на заданому наборі номіналів ефективніше використовувати жадібний алгоритм
Якщо потрібен гарантовано оптимальний набір монет - тоді використовувати динамічний алгоритм

# Завдання 2. Інтеграл методом Монте-Карло

 Оцінюємо площу під графіком `f(x) = x^3 + 2x` на відрізку `[0, 3]`. Випадкові точки генеруються у прямокутнику шириною `3` та висотою `f(3) = 33`.

Для перевірки використано аналітичне обчислення:

`x^4/4 + x^2 = 29.25`.

Були використані різні вибірки: `(1_000, 10_000, 100_000)`
При збільшені кількості випадкових точок результат все ближчий до аналітичного.
